Getting Started

Quick Setup Guide

  • Add Your Business Info: Set up your company name, logo, and preferred currency
  • Import Clients: Add your existing client contacts manually or import from a CSV file
  • Customize Settings: Configure notifications, themes, and preferences
  • Start Organizing: Begin tracking projects, tasks, and communications

Common Issues & Solutions

Login Problems

If you're having trouble logging in:

  • Check that Caps Lock is off
  • Verify your email address is entered correctly
  • Try resetting your password using the "Forgot Password" link
  • Clear your app cache/data if using the mobile app
  • Ensure you have a stable internet connection

Synchronization Issues

For Premium users experiencing sync problems:

  • Check your internet connection stability
  • Verify your subscription is active and up to date
  • Restart the app to trigger a manual sync
  • Check that sync permissions are enabled in app settings
  • Contact support if issues persist beyond 24 hours

Invoice Generation Problems

If invoices aren't generating correctly:

  • Verify all required fields are filled out (client info, items/services, amounts)
  • Check that your business information is complete in profile settings
  • Ensure you have premium subscription for advanced invoice features
  • Confirm PDF export permissions are granted to the app
  • Try regenerating the invoice if formatting appears incorrect

Technical Support

Supported Platforms

Clientist is available on:

  • iOS: iPhone and iPad (iOS 12.0 or later)
  • Android: Devices running Android 8.0 (Oreo) or later
  • Web: Chrome, Firefox, Safari, Edge (latest versions)

System Requirements

  • Minimum 2GB RAM for optimal performance
  • Stable internet connection for sync features
  • Sufficient storage space for local data and attachments
  • Bluetooth capability for device pairing features (optional)

Known Issues

Currently known issues that we're working to resolve:

  • Rare sync delays during peak usage hours (typically resolves within 30 minutes)
  • Occasional slow loading on older Android devices with extensive data sets
  • Minor UI alignment issues on some tablet screen sizes
